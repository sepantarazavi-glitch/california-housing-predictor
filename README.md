# California Housing Price Predictor

An end-to-end machine learning project that predicts median house values in California based on demographic and geographical features. The trained model is deployed as an interactive web application using Streamlit.

## Features
- Exploratory data analysis and feature inspection using Python and Pandas.
- Machine learning regression model trained with Scikit-Learn (Random Forest Regressor).
- Interactive web interface allowing users to adjust property parameters and see real-time price predictions.

## Tech Stack
- **Python**
- **Pandas & NumPy**
- **Scikit-Learn**
- **Streamlit**
- **Pickle**
